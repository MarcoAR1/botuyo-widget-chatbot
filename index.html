Instalación

Para usar este widget en tu sitio web, agrega este código antes del cierre del </body>:

<!-- Paseo Libre Chat Widget -->
<script src="https://cdn.paseolibre.com/chat-widget.js"></script>
<script>
  PaseoLibreChat.init({
    apiKey: 'tu-api-key-aqui',
    apiBaseUrl: 'https://api.paseolibre.com',
    theme: {
      primaryColor: '#10b981',
      botName: 'Asistente Paseo Libre',
      position: 'bottom-right'
    }
  });
</script>
