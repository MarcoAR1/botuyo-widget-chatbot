🧪 Funcionalidades a Probar

  • Iniciar llamada (botón Start Call)
  • Conectar WebSocket y enviar auth + start_call
  • Capturar audio con AudioWorklet (PCM 16kHz)
  • Recibir transcripción en tiempo real
  • Escuchar respuesta del bot (TTS)
  • Terminar llamada (botón End Call)
  • Timer de duración de llamada

📡 Protocolo WebSocket

Mensaje Dirección Descripción
start_call → Server Inicia la llamada
call_started ← Server Llamada establecida
listening ← Server VAD detectó voz
transcription ← Server Texto transcrito
speaking ← Server Bot respondiendo
response_text ← Server Texto de respuesta
done ← Server Turno completo
end_call → Server Termina la llamada

👇 Cómo Probar

  1. Asegurate que el backend esté corriendo en localhost:3000
  2. Hacé click en el botón del chat (abajo a la derecha)
  3. Buscá el botón 📞 Start Call
  4. Aceptá el permiso de micrófono
  5. ¡Hablá con el bot!
