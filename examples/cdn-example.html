🎉 Ejemplo CDN del Chat Widget

Este es un ejemplo de integración del Paseo Libre Chat Widget usando CDN. No requiere React, Next.js ni ningún framework - solo JavaScript vanilla.

Estado: Inicializando widget...

Código de integración:

<script src="https://cdn.paseolibre.com/chat-widget.js"></script>
<script>
  const widget = PaseoLibreChat.init({
    apiKey: 'demo-api-key',
    apiBaseUrl: 'https://api.paseolibre.com',
    theme: {
      primaryColor: '#10b981',
      botName: 'Demo Bot',
      position: 'bottom-right'
    }
  });
</script>
